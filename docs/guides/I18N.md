# I18N — Localization Infrastructure (Track 3)

> Worktree: `wt-i18n` (`worktree-track3-i18n` @ `0268227`) — i18n infra, ARBs, delegate wiring.

## Stack

- **`flutter_localizations` (SDK)** + **`intl: ^0.20.2`** — ICU/plural support.
- **`flutter: generate: true`** in `pubspec.yaml` — enables `gen-l10n`.
- **`l10n.yaml`**:
  ```yaml
  arb-dir: lib/l10n
  template-arb-file: app_en.arb
  output-localization-file: app_localizations.dart
  output-dir: lib/l10n
  nullable-getter: true
  format: true
  ```
  (`synthetic-package` was removed — deprecated and has no effect.)
  `nullable-getter: true` lets tests pump widgets without a `MaterialApp` delegate — `AppLocalizations.maybeOf(context)` falls back to English (`AppLocalizationsEn`).

## Delegate wiring

- **`lib/src/flux_app.dart`** — both `FinnBootstrap`'s loading `MaterialApp` and `FluxApp`'s `MaterialApp` declare:
  ```dart
  localizationsDelegates: const [
    AppLocalizations.delegate,
    GlobalMaterialLocalizations.delegate,
    GlobalWidgetsLocalizations.delegate,
    GlobalCupertinoLocalizations.delegate,
  ],
  supportedLocales: AppLocalizations.supportedLocales, // [de,en,es,fr,it]
  ```
  `_UnsupportedDevicePage` now uses `maybeOf` for title/body.
- **`lib/l10n/l10n_helper.dart`** — `L10n.of(context)` helper (EN fallback). The generated file also exposes `AppLocalizations.maybeOf(context)` that `lookupAppLocalizations(const Locale('en'))` when delegates are absent (tests).
- `flutter gen-l10n` output is in `lib/l10n/` because `synthetic-package: false` (now default). The file is re-patched after each generation to re-add `maybeOf`.

## Workflow

1. Add/edit keys in `lib/l10n/app_en.arb` (with `@key` metadata + `placeholders` for interpolations).
2. Copy to `app_it/es/fr/de.arb` with proper translations (update `@@locale`).
3. `flutter gen-l10n`
4. Re-apply `maybeOf` patch (overwritten on generation):
   ```sh
   python3 -c "import pathlib; p=pathlib.Path('lib/l10n/app_localizations.dart'); t=p.read_text(); t=t.replace('static AppLocalizations? of(BuildContext context) {\\n    return Localizations.of<AppLocalizations>(context, AppLocalizations);\\n  }','static AppLocalizations? of(BuildContext context) {\\n    return Localizations.of<AppLocalizations>(context, AppLocalizations);\\n  }\\n\\n  static AppLocalizations maybeOf(BuildContext context) {\\n    return Localizations.of<AppLocalizations>(context, AppLocalizations) ?? lookupAppLocalizations(const Locale(\\'en\\'));\\n  }'); p.write_text(t)"
   ```
5. Replace literals with `AppLocalizations.maybeOf(context).<key>` (never `!` in widgets that may be pumped without delegates). Remove `const` from any widget whose subtree now contains `maybeOf`.
