# 0008 — A licence-clean voice: Supertonic 3, and sherpa-onnx without espeak-ng

**Status.** Accepted 2026-10-02. Implemented; measured on a Xiaomi 2109119DG (Snapdragon 778G). Supersedes the text-to-speech and licensing parts of [0007](0007-live-voice-and-spoken-replies.md).

**Context.** 0007 shipped Piper voices run by the prebuilt sherpa-onnx library. That library statically contains espeak-ng (GPL-3.0-or-later), and each voice archive carried espeak-ng's data. FinnAI is proprietary, so this was a known, accepted-for-the-beta risk. Testers also found the voices unpleasant, and there was no Hindi voice.

**Decision.**
- **Remove espeak-ng.** sherpa-onnx is built from source (`tool/rebuild_sherpa_android.sh`, `-DSHERPA_ONNX_ENABLE_TTS=OFF`) and wired in through `dependency_overrides` in `pubspec.yaml` (`third_party/sherpa_onnx_android_arm64/`). Speech recognition (Whisper, Silero VAD) is unchanged. The script fails if `espeak[_-]ng` is still in the library; run it after any sherpa-onnx upgrade.
- **A different voice.** Supertonic 3 (Supertone): 99M parameters, 31 languages, four styles, 44.1 kHz. Weights are BigScience OpenRAIL-M; sample code is MIT. It reads *characters*, so it needs no phonemizer, and one model replaces one-voice-per-language: it is a single ~398 MB download (four ONNX models, config, indexer, four style files), pinned by size and SHA-256 in `tts/tts_voice_catalog.dart`.
- **Our own runner.** `android/app/src/main/cpp/finn_supertonic.cc` drives the four models over ONNX Runtime (MIT) and is built by Gradle (`externalNativeBuild`, `arm64-v8a`). Dart reaches it by FFI (`tts/supertonic_native.dart`) on a worker isolate (`tts/supertonic_worker.dart`); text normalisation (NFKD, using a table generated by `tool/gen_supertonic_nfkd.py`) happens in Dart (`tts/supertonic_text.dart`). `LocalTtsBackend` replaces the Piper backend; `FallbackTtsBackend` still uses the platform engine when the voice is not installed.
- **Languages.** Every language the voice supports can be read, so Russian and Hindi are no longer silent. `pickSpeechLanguage` still decides by script, then by what Whisper heard, then by the phone.
- **Upgrades.** `TtsVoiceStore` deletes the retired Piper voices and espeak data on first run (`espeak-ng-data`, `archives`).
- **Use restrictions.** OpenRAIL-M passes its use restrictions on to users of the model. The in-app licence screen and THIRD_PARTY_NOTICES.md state them. FinnAI never clones a voice and reads only its own replies.

**Consequences.**
- Measured on the phone: model load 1.3 s; real-time factor 0.42-0.48 (4.7 s of English audio in 2.1 s), all six probe languages synthesised. It is slower than Piper (0.3-0.65x was measured then on shorter, smaller models), but still faster than speech, and the first sentence is spoken while the next is made.
- The download is ~398 MB instead of ~21 MB per language. It is offered with the language model and on the upgrade screen, and is optional: with no voice, replies are read by the platform engine if there is one.
- The ~100 MB resident ONNX Runtime sessions are freed by `release()`; the voice is loaded when voice mode opens (`prepare`).
- The Hugging Face namespace is `supertone-oss-archive`; upstream is archived, which for a pinned, hash-checked file is a stability gain, not a risk, but the URL could move. Mirror the files before a public release.
- `FINN_TTS_PROBE` (a `--dart-define`, `tts/tts_probe.dart`) synthesises one sentence per language and logs timings; it exists for device checks and does nothing in a normal build.
- Not legal advice: the licence position (OpenRAIL-M, Apache-2.0, MIT) was read, not reviewed by counsel.
