# 0007 — Live voice: spoken replies on the device, a hands-free loop, short answers

**Status.** Accepted 2026-10-01. **The text-to-speech and licence parts are superseded by [0008](0008-licence-clean-voice.md)** (Piper and espeak-ng removed). Implemented; measured on a Xiaomi 2109119DG (Snapdragon 778G). Extends [0006](0006-on-device-speech-recognition.md).

**Context.** After 0006 the user could speak, but had to tap to send, and the phone had no text-to-speech engine at all, so answers were silent. A voice turn also took ~3.7 s to the first sound, most of it the language model reading a 440-token prompt.

**Decision.**
- **Text-to-speech.** Piper VITS voices, int8 (~21 MB each), run by sherpa-onnx on a worker isolate (`tts/tts_worker.dart`); audio goes to `flutter_pcm_sound`. One voice per language in `tts/tts_voice_catalog.dart`, pinned by the size and SHA-256 GitHub publishes for the release asset. English and the phone's language download with the language model (first run and the upgrade screen, as `InstallAddon`s). `FallbackTtsBackend` uses the platform engine only when no on-device voice fits.
- **Licences.** A voice is listed only if its training data may be redistributed: public domain (English LJ Speech), CC0 (German, Spanish, Italian, Russian), CC BY 4.0 (French Siwis, credited in THIRD_PARTY_NOTICES). Rejected: Lessac (Blizzard 2013 research licence), Ryan/Ruslan/Pratham/Priyamvada (CC BY-NC-SA), Irina (unknown), Rohan (IITM research licence), Tom (AGPL). **There is no Hindi voice**; Hindi and Russian text is never read with the English voice. A test names the rejected voices so one is not added back without a licence check.
- **Which voice.** `pickSpeechLanguage` decides from the text's script first (Cyrillic is Russian, Devanagari is Hindi), then the language Whisper heard, then the phone's.
- **A live conversation** (`VoiceChatController.startLive`): listen, send the transcript as soon as the speaker stops, think, speak, listen again after 350 ms. It ends on the cross, on 10 s of silence, on an error, or when the app is backgrounded. It does not reopen the microphone if replies are not spoken, if the user interrupted, or if the reply was empty.
- **Faster turns.** (1) No tap to send. (2) End-of-speech silence 0.9 -> 0.7 s. (3) A *spoken turn* (`PromptAnalysis.spoken`) replaces the ~230-token task instruction with a ~50-token one and caps the output at 160 tokens; a typed turn is untouched. (4) The first piece of a reply is spoken at a comma or after ~70 characters, not at the end of the first sentence. (5) A spoken reply is stopped after three sentences (`ReplyChunker.spokenReplyMaxSentences`): the model is asked for two and does not always oblige. (6) A spoken turn skips the speculative `factCheck` web search; `explicit` and `fresh` searches still run. (7) TTS uses 2 threads so the language model keeps its cores (3 threads cost it ~16 -> ~10 tokens/s).
- **The pill** (`chat/widgets/voice_pill.dart`) follows the microphone while listening, the voice while speaking and breathes while thinking, with a one-line caption. Reduced motion holds it still.
- **Chat -> voice is one motion** (`chat/widgets/voice_morph_bar.dart`, driven by one controller in the composer, 760 ms in, 540 ms out, `easeInOutCubic`). The message field *is* the pill: it narrows, its text fades first, its white gives way to the colour; the attach button turns into the cross; the dark voice button hands over to the light microphone with a small pulse; the row closes in on its centre; the caption opens last. It reverses from wherever it is if interrupted. Chosen against the Material "emphasized" curve, which spends nearly all of its change in the first third and was over before it could be seen on the phone. Settled in chat the pill stops its ticker, so an idle chat screen does not repaint.
- **A bug worth remembering:** a `BoxDecoration` with both a `color` and a `gradient` draws the gradient *through the colour's alpha*. The white of the field fading to alpha 0 made the colour pill invisible; the colour is therefore its own layer and a test forbids both on one decoration.

**Known licensing risk: espeak-ng is GPL.** sherpa-onnx's native library statically contains espeak-ng (GPL-3.0-or-later), used to turn text into phonemes for Piper. FinnAI is proprietary, so this is a real tension, and it applies from version 9 (the first release with sherpa). It has been in the APK since [0006](0006-on-device-speech-recognition.md), because the prebuilt library includes TTS even when only recognition is used. **Owner decision 2026-10-01: ship version 9 with the prebuilt library, accepting the risk, with the espeak-ng notice and a source pointer in the in-app licence screen and THIRD_PARTY_NOTICES.md.** This is not a legal opinion; none was obtained. The ways out, in order of effort: get counsel's view; build sherpa-onnx from source with `-DSHERPA_ONNX_ENABLE_TTS=OFF` (removes espeak-ng; speech recognition keeps working, on-device voices stop, spoken replies fall back to the platform engine; needs ~100 MB of source and ONNX Runtime downloads); or a text-to-speech runtime that does not use espeak-ng. Revisit before any release beyond the beta.

**Consequences.**
- The language model's measured cost: time to first text 3.0 s -> 1.5 s on the same kind of question; first audio 3.7 s -> 2.1-4.1 s depending on how long the first sentence is. Speech synthesis runs at 0.3-0.65x real time, so it keeps up.
- A spoken answer is short and may be cut: the shown message ends at the third sentence. The user can ask for more.
- Typed turns, the eval suites and their gates are unchanged; the spoken path has no eval of its own yet.
- Hindi can be heard (poorly: Whisper base) but not answered aloud until a redistributable voice exists.
- Each added language is ~21 MB more on disk; only English and the phone's language are fetched up front. A language the user speaks that has no downloaded voice falls back to English for Latin scripts and to silence otherwise; fetching it on demand is not built.
- Log tags: `FINN_VOICE` (`transcript`, `first_text_ms`, `first_audio_ms`), `FINN_TTS` (`load_ms`, `synth_ms`, `audio_ms`, `rtf`, `unpack_ms`).
