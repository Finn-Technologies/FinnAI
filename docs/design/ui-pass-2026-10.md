## First-party references (already in use, not re-browsed in this pass)

- **Apple Siri app and Liquid Glass (iOS 26):** the voice light as an edge glow; glass only on small floating
  surfaces. FinnAI's voice light is one shader pass (`shaders/voice_glow.frag`), glass only on the floating sheets.
- **Apple Shortcuts (iOS 26):** coloured tiles per automation with a run button; FinnAI's Flows grid.
- **Cursor for iOS:** sessions as rows with a state dot and "+added −removed"; FinnAI Code's sidebar.
- **libraries.dev:** Inter-like grotesk with 1.5px stroke icons; FinnAI's Geist + Lucide 300.
- **Hark:** a calm voice surface; FinnAI's voice mode.

## What this pass took from the board

1. **One component set for both apps** (6, 7, 8): Code uses the chat's composer, header, greeting, bubbles,
   error card, thinking orb and confirm pills (`lib/src/shared/widgets/finn_*`).
2. **Touch targets** (13, 18): every control in Code's status line, terminal bar and approvals is 48dp.
3. **Contrast on colour** (14): Flows tiles keep AA contrast for their text.
4. **Motion only for a change of state** (1, 19): the greeting reveal, the orb while waiting, the composer fuse;
   all stop when settled.

### Frame timing

Android emulator (API 37, 1080x2400, `-gpu host`), profile build with `--dart-define=FINN_FRAME_LOG=true`, read from
the `FINN_FRAMES` lines. Before = a build of `219a0ae`; after = `1286334`. p50/p90 are frame-weighted means of the
2-second windows' percentiles; "worst p99" is the worst window. Budget 16.7 ms. An emulator, not a phone: read the
differences, not the absolute values.

| Scenario | Build p50 / p90 ms (before → after) | Raster p50 / p90 ms (before → after) | Worst p99 raster ms | Frames over budget |
|---|---|---|---|---|
| "+" sheet open/close ×8 | 0.7 / 0.9 → 0.7 / 1.2 | 3.0 / 5.8 → 1.8 / 3.1 | 23.4 → 9.4 | 13 → 0 |
| Sidebar open/close ×6 | 0.4 / 0.6 → 0.5 / 0.8 | 2.6 / 3.8 → 2.8 / 4.4 | 8.1 → 15.9 | 0 → 0 |
| Flows page push/pop ×4 (warm)¹ | 0.4 / 0.6 → 0.8 / 2.3 | 1.6 / 2.6 → 1.8 / 3.1 | 6.4 → 11.3 | 0 → 0 |
| Chat field tap → keyboard fuse ×5 | not measurable² | — → 1.7 / 3.8 | — → 8.1 | — → 0 |

¹ The first run after install had one 214.6 ms raster frame on the first
Flows open (14 frames over budget in that run) and did not recur; not explained. ² Before this pass the chat field
closed the keyboard ~140 ms after opening it (see the PLAN entry), so there was no fuse to measure.

The "+" sheet was also measured against the previous installed build before any change (raster p50 4.4, p90 7.4,
worst 25.8, 14 over budget) and after removing its backdrop blur alone (2.1 / 3.6 / 10.3, 0 over).
